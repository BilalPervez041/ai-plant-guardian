# 🌱 AI Plant Guardian — Plant Disease Detection

An AI-powered Android application designed to identify plant diseases using deep learning and on-device AI processing.

## 📌 Project Overview

AI Plant Guardian helps users identify plant diseases through an Android application powered by a deep learning model. TensorFlow Lite enables on-device inference, supporting offline plant disease classification.

## 🎯 Objective

To make plant disease identification more accessible through an AI-powered mobile application.

## ✨ Key Features

- 🌿 Plant disease identification
- 🤖 Deep learning-based classification
- 📱 Android mobile application
- ⚡ TensorFlow Lite model integration
- 📡 Offline inference support

## 🛠️ Technologies

- Python
- TensorFlow
- TensorFlow Lite
- Deep Learning
- Android

## ⚙️ Project Workflow

1. Capture or select a plant image.
2. Process the image for model input.
3. Run inference using the trained model.
4. Display the predicted plant disease class.

*The workflow should be adjusted if the implemented application uses a different process.*

Developed as an AI-based plant disease detection project.
